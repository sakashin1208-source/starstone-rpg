# 星石の勇者 3D / Starstone Hero 3D

**Doll × Diorama 3D RPG**

Godot 4.x、Blender、Figma、HyperFrames、およびAIエージェント（Antigravity / Codex / Claude Code等）を活用して制作される、AI主体型ゲーム開発スタジオの実証プロジェクトです。

---

## 🎮 プロジェクト概要
- **ジャンル**: 3D RPG
- **ビジュアルスタイル**: ドール × ジオラマ (Doll × Diorama)
- **第一マイルストーン**: 約10分で完結する高品質な「Vertical Slice」の完成
- **ゲームエンジン**: Godot 4.x (GDScript)
- **3D制作・自動化**: Blender 4.x (Python / bpy)

---

## 📂 ディレクトリ構成
- `game/`: Godotプロジェクト本体（シーン、スクリプト、アセット、データ）
- `blender/`: Blender編集原本（.blendファイル等）
- `pipeline/`: Blender自動化スクリプト、検証ツール、ビルドパイプライン
- `figma/`: UI/UXデザイン設計資料、Design Tokens
- `hyperframes/`: プロモーション映像・PV制作用アセット
- `docs/`: 仕様書・アーキテクチャ・開発ログ等のドキュメント
- `AGENTS.md`: AIエージェント開発憲法（全69条）
